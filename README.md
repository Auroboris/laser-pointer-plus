# Laser Pointer+

A [StarMash](https://starmash.airmash.rocks) / SWAM extension that adds some girth, length, & shades to Moz's OG laser pointer. Can function at map edges, has a new pointer 'reload' feature, and the beam origin can be adjusted. 

Install URL: `https://cdn.jsdelivr.net/gh/Auroboris/laser-pointer-plus@cc8197efb5efc396a34993657c67a7b8004f2cbb/extension.js`

## Usage

Install the extension, reload StarMash, then open **Mod Settings → Laser Pointer+**.

- Toggle the laser on or off with any chosen key (`P` by default).
- Drag the sliders to change its width and length.
- Move the beam origin forward or backward. `0` keeps the standard position.
- Choose a preset color or enter a custom HEX color.
- Hide the beam after each confirmed shot and choose a return delay from 100–2000 ms.
